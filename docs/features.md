# Features

[한국어](features.ko.md)

Items use the states `[ ]` waiting, `[~]` active, `[o]` complete, `[!]` held and `[-]` closed.
- [o] G1 — P0: The git section checks git and the repository of the project. Input: a team member of the clubhouse needs a git worktree, and a project folder that is not a repository, or a machine without git, has none. Expected: the plugin contributes the sidebar section `git.status`, which a person places through the sidebar sets of the settings; when the section shows and when `git.check` runs, it runs the declared program `git --version`; without git it shows that git is missing, with the button 설치 that runs `xcode-select --install` through a declared program and the button 다시 확인; with git, when the project root is not inside a work tree (`git rev-parse --is-inside-work-tree`), it shows that the folder is not a repository with the button `git init`, which runs `git init` in the project root and checks again; otherwise it shows the branch (`git branch --show-current`). The section shows every result and failure on its page, records each failure through `runtime.error`, and publishes the status `git.state` ([git section](spec/git.md)). Done in code: `ui/git-state.js`, `ui/status.js`, `ui/status.html`, `plugin.json`, `test/git-state.test.mjs` and `test/manifest-shape.test.mjs`; Red/Green of `sectionView` in `test/git-state.test.mjs`. Requires core F1152 (programs of a plugin with sections), so the engine range is `^0.0.53`. Verification: in a debug window of a core build with F1152, a project folder outside a repository showed the git version with the buttons `git init` and 다시 확인, `git.state` read `repository: "outside"`, the element `git.status.init` created `.git` and the section showed `브랜치: main` with `git.state` `repository: "inside", branch: "main"`; a run with arguments that differ from the slots showed the refusal of the host in the section and was recorded as `workbench.record.error`. The state `missing` is checked by the tests of `versionState` and `sectionView`, because the machine of the check has git.
